# @glob-ui/layout

The rules behind every GlobUI layout: a layout owns the scroll, a template fixes part of it, and a page only fills the slots.

## Install

```bash
pnpm add @glob-ui/layout
```

## Documentation

Full docs, examples and the accessibility table: [Layouts](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/layouts/index.mdx).
