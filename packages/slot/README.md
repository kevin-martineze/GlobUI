# @glob-ui/slot

Renders its single child with the props, className, handlers and ref merged in. It is how `asChild` works.

## Install

```bash
pnpm add @glob-ui/slot
```

## Documentation

Full docs, examples and the accessibility table: [Slot](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/utilities/slot.mdx).
