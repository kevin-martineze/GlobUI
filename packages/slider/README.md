# @glob-ui/slider

A range input with a visible fill. It is the native `<input type="range">`, so keyboard, forms and screen readers work as usual.

## Install

```bash
pnpm add @glob-ui/slider
```

## Documentation

Full docs, examples and the accessibility table: [Slider](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/slider.mdx).
