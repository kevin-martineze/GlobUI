# @glob-ui/toast

Short, timed messages. Call `toast()` from anywhere, and mount `<Toaster />` once.

## Install

```bash
pnpm add @glob-ui/toast
```

## Documentation

Full docs, examples and the accessibility table: [Toast](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/toast.mdx).
