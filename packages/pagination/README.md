# @glob-ui/pagination

Page navigation: previous and next, page links and ellipses. `getPageRange` computes which pages to show.

## Install

```bash
pnpm add @glob-ui/pagination
```

## Documentation

Full docs, examples and the accessibility table: [Pagination](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/pagination.mdx).
