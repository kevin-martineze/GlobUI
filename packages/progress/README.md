# @glob-ui/progress

A progress bar, determinate with a value or indeterminate while the length is unknown.

## Install

```bash
pnpm add @glob-ui/progress
```

## Documentation

Full docs, examples and the accessibility table: [Progress](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/progress.mdx).
