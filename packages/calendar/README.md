# @glob-ui/calendar

A month grid for picking one day or a range of days. Values are ISO date strings ("YYYY-MM-DD"), so they serialize and compare without time zones.

## Install

```bash
pnpm add @glob-ui/calendar
```

## Documentation

Full docs, examples and the accessibility table: [Calendar](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/calendar.mdx).
