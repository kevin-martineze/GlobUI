# @glob-ui/switch

An on/off control with `role="switch"`, controlled or uncontrolled, with an optional form value.

## Install

```bash
pnpm add @glob-ui/switch
```

## Documentation

Full docs, examples and the accessibility table: [Switch](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/switch.mdx).
