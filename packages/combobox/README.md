# @glob-ui/combobox

A text input with a filtered list: type to search, arrows to move, Enter to choose. The API mirrors Select.

## Install

```bash
pnpm add @glob-ui/combobox
```

## Documentation

Full docs, examples and the accessibility table: [Combobox](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/combobox.mdx).
