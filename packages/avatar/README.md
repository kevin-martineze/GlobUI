# @glob-ui/avatar

A user picture with initials as the fallback, and a stacked group with an overflow count.

## Install

```bash
pnpm add @glob-ui/avatar
```

## Documentation

Full docs, examples and the accessibility table: [Avatar](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/avatar.mdx).
