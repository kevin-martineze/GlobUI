# @glob-ui/select

A single-choice dropdown that follows the WAI-ARIA select-only combobox pattern, with search above eight options.

## Install

```bash
pnpm add @glob-ui/select
```

## Documentation

Full docs, examples and the accessibility table: [Select](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/select.mdx).
