# @glob-ui/accordion

Sections that open and close. Single or multiple open at once, optionally collapsible.

## Install

```bash
pnpm add @glob-ui/accordion
```

## Documentation

Full docs, examples and the accessibility table: [Accordion](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/accordion.mdx).
