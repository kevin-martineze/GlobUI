# @glob-ui/radio-group

A group of native radios: one tab stop, arrows move and select.

## Install

```bash
pnpm add @glob-ui/radio-group
```

## Documentation

Full docs, examples and the accessibility table: [Radio group](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/radio-group.mdx).
