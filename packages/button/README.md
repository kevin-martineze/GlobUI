# @glob-ui/button

A button that can render as a link, and shows a loading state without changing its width.

## Install

```bash
pnpm add @glob-ui/button
```

## Documentation

Full docs, examples and the accessibility table: [Button](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/button.mdx).
