# @glob-ui/toggle

A button with a pressed state, and a group of them with single or multiple selection.

## Install

```bash
pnpm add @glob-ui/toggle
```

## Documentation

Full docs, examples and the accessibility table: [Toggle](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/toggle.mdx).
