# @glob-ui/utils

Joins class names and merges Tailwind classes, so the last conflicting class wins. It knows the GlobUI radius and shadow scales.

> **Internal API.** This package is used by the other GlobUI packages. Its exports can change in any release, so depend on the component packages instead.

## Install

```bash
pnpm add @glob-ui/utils
```

Full docs, examples and the accessibility table: [cn()](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/utilities/cn.mdx).
