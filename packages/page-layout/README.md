# @glob-ui/page-layout

A page inside a layout: a sticky header, the content, and an optional aside that sticks from `lg`. It sets no height and no overflow, and it is server-safe.

## Install

```bash
pnpm add @glob-ui/page-layout
```

## Documentation

Full docs, examples and the accessibility table: [PageLayout](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/layouts/page.mdx).
