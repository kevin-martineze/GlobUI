# @glob-ui/textarea

A multi-line text field with the same sizes and states as Input.

## Install

```bash
pnpm add @glob-ui/textarea
```

## Documentation

Full docs, examples and the accessibility table: [Textarea](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/textarea.mdx).
