# @glob-ui/checkbox

A native checkbox with a label, sizes, and an indeterminate state for groups.

## Install

```bash
pnpm add @glob-ui/checkbox
```

## Documentation

Full docs, examples and the accessibility table: [Checkbox](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/checkbox.mdx).
