# @glob-ui/stacked-layout

A document layout: the page scrolls as a document, and the header stays visible. Use it for simple apps, portals and docs.

## Install

```bash
pnpm add @glob-ui/stacked-layout
```

## Documentation

Full docs, examples and the accessibility table: [StackedLayout](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/layouts/stacked.mdx).
