# @glob-ui/segmented

A row of mutually exclusive options that looks like a control group, for example Day, Week, Month.

## Install

```bash
pnpm add @glob-ui/segmented
```

## Documentation

Full docs, examples and the accessibility table: [Segmented control](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/segmented.mdx).
