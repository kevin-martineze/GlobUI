# @glob-ui/tooltip

A short description that appears on hover or keyboard focus. It stays open while the pointer is over it.

## Install

```bash
pnpm add @glob-ui/tooltip
```

## Documentation

Full docs, examples and the accessibility table: [Tooltip](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/tooltip.mdx).
