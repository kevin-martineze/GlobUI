# @glob-ui/app-shell-layout

An app shell for dashboards and admin apps. The viewport never scrolls: the header and sidebar stay in place, and only the main region scrolls.

## Install

```bash
pnpm add @glob-ui/app-shell-layout
```

## Documentation

Full docs, examples and the accessibility table: [AppShellLayout](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/layouts/app-shell.mdx).
