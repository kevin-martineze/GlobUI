# @glob-ui/styles

GlobUI design tokens (CSS custom properties) and the Tailwind theme mapping.

## Install

```bash
pnpm add @glob-ui/styles
```

In your global stylesheet (see the [installation guide](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/installation.mdx)):

```css
@import "tailwindcss";
@import "@glob-ui/styles";
```
