# @glob-ui/command

A command palette: a search field over grouped, filtered, keyboard-driven actions. Items are plain JSX, so icons and shortcuts are free.

## Install

```bash
pnpm add @glob-ui/command
```

## Documentation

Full docs, examples and the accessibility table: [Command](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/command.mdx).
