# @glob-ui/multi-select

Pick several options. The selected options show as removable chips.

## Install

```bash
pnpm add @glob-ui/multi-select
```

## Documentation

Full docs, examples and the accessibility table: [Multi-select](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/multi-select.mdx).
