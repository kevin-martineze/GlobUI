# @glob-ui/table

Styled native table parts: header, body, footer, rows and cells, with density, striped rows, a sticky header and right-aligned numbers.

## Install

```bash
pnpm add @glob-ui/table
```

## Documentation

Full docs, examples and the accessibility table: [Table](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/table.mdx).
