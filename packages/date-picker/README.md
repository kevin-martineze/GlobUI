# @glob-ui/date-picker

A date field. The trigger shows the value and opens a calendar in a popover, for one day or a range, with optional presets.

## Install

```bash
pnpm add @glob-ui/date-picker
```

## Documentation

Full docs, examples and the accessibility table: [Date picker](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/date-picker.mdx).
