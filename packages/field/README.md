# @glob-ui/field

Wraps one form control with a label, a description and an error, and wires their ARIA attributes to it.

## Install

```bash
pnpm add @glob-ui/field
```

## Documentation

Full docs, examples and the accessibility table: [Field](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/field.mdx).
