# @glob-ui/phone-input

A telephone field with a country picker. The picker searches by country name, dial code and ISO code.

## Install

```bash
pnpm add @glob-ui/phone-input
```

## Documentation

Full docs, examples and the accessibility table: [Phone input](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/phone-input.mdx).
