# @glob-ui/alert-dialog

A modal that asks the user to confirm a decision. The backdrop does not close it; the user answers with Cancel or the action.

## Install

```bash
pnpm add @glob-ui/alert-dialog
```

## Documentation

Full docs, examples and the accessibility table: [Alert dialog](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/alert-dialog.mdx).
