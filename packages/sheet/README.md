# @glob-ui/sheet

A panel that slides in from an edge. It is a Dialog: same focus handling, Escape, backdrop and scroll lock.

## Install

```bash
pnpm add @glob-ui/sheet
```

## Documentation

Full docs, examples and the accessibility table: [Sheet](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/sheet.mdx).
