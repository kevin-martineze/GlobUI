# @glob-ui/popover

Floating content next to a trigger, for example a small form. Non-modal: focus moves in, but nothing is trapped.

## Install

```bash
pnpm add @glob-ui/popover
```

## Documentation

Full docs, examples and the accessibility table: [Popover](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/popover.mdx).
