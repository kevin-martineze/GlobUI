# @glob-ui/dialog

A modal dialog on the native `<dialog>` element. Focus moves in, Escape closes it, and focus returns to the trigger.

## Install

```bash
pnpm add @glob-ui/dialog
```

## Documentation

Full docs, examples and the accessibility table: [Dialog](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/dialog.mdx).
