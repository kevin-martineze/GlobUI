# @glob-ui/data-table

A table with sorting, search, pagination, row selection and column visibility, each opt-in. Built on TanStack Table v9.

## Install

```bash
pnpm add @glob-ui/data-table
```

## Documentation

Full docs, examples and the accessibility table: [Data table](https://github.com/kevin-martineze/GlobUI/tree/main/apps/docs/content/docs/components/data-table.mdx).
