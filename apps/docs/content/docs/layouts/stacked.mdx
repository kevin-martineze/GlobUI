## Slots

The layout is a grid of slots. A prop fills each slot, and each slot is fixed or scroll.

<SlotMap layout="StackedLayout" />

| Slot | Element | Scroll | Notes |
| --- | --- | --- | --- |
| `header` | `<header>` | fixed | Sticks to the top of the document. |
| `main` | `<main>` | scroll | The page, in document flow. The document is the scroller. It has no padding: put a `PageLayout` in it. |
| `footer` | `<footer>` | fixed | At the end of the document. It is not a scroller. |

- **fixed**: the slot never scrolls. It stays in place, or sticks.
- **scroll**: the one region that scrolls for this part of the screen.

## Accessibility

| Key or action | Behaviour |
| --- | --- |
| Skip to content | The first Tab stop. Enter moves focus to `main`. |
| mobileNav | Opens from `LayoutNavTrigger` in a Sheet below `lg`, the same as the app shell. |

**ARIA.** Landmarks: `banner`, one `main`, and `contentinfo` for the footer. `useLayoutScroll()` returns `document.scrollingElement`.
