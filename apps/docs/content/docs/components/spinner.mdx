## Accessibility

| Key or action | Behaviour |
| --- | --- |
| Screen readers | `role="status"` with an `aria-label` (default "Loading"). Change it to describe what is loading. |

**ARIA.** Spinners need a label that says what is loading. Set `aria-label`, for example "Saving changes".
