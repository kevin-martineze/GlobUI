## Accessibility

| Key or action | Behaviour |
| --- | --- |
| Space, Enter | Toggles the switch. |
| Tab | Focuses it. |

**ARIA.** `role="switch"` with `aria-checked`. Give it a name with `aria-label` or a visible label, for example a Field.
