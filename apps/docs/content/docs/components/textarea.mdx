## Accessibility

| Key or action | Behaviour |
| --- | --- |
| Tab | Focuses the textarea. |
| Enter | Inserts a line break (native behaviour). |

**ARIA.** A native `<textarea>`. Give it a name with `Field` or `aria-label`.
